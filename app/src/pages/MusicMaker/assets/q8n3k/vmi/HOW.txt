This folder is the scene q8n3k.

The drawing stays the source. This folder is the delivery.
An object is one thing in the work. Another drawing of that same thing is another position.
Each frame is one full-canvas picture. It is not cut down to a small sprite.
The picture name is six hex digits, SSSXXX.
SSS is the state. 000 rest, 001 hover, 002 pressed, 003 after. XXX is the frame.
Every picture is the whole canvas. Empty pixels stay empty, so the pictures stack.
The object list is the stack. The top row is behind.

Canvas 960 x 317. Source m4c7w2.jpg (jpeg).
Webamp playlist is off.
